## 6. What it does

OBS Screen Studio brings "screen studio" style motion to plain OBS recordings: smooth click-to-zoom on the
cursor, animated transitions between zoom levels, and keyboard-driven zoom control, so a tutorial recording
looks edited without a separate editor.

How it works: one Lua script (about 3,200 lines) that reads the global cursor position and mouse-button state
through LuaJIT FFI (`user32` `GetCursorPos` / `GetKeyState`) and animates a transform on a source or group.
There is no OS-level hook; it polls while OBS runs.
