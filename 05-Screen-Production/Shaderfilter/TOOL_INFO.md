## 6. What it does

Shaderfilter applies a custom shader to any source as a filter. You load a `.shader` or `.effect` file, and the
annotations in that file become OBS properties (sliders, colors, checkboxes, textures) you can animate with
OBS's normal filter controls. The repository ships 165 example shaders and effects: blur, bloom, chroma key
helpers, CRT/scanline looks, transitions, masks, color correction, and more.

How it works: a C++ OBS plugin that compiles the shader with OBS's graphics API and renders it as a filter pass.
Parameters declared in the shader header appear in the filter UI.
