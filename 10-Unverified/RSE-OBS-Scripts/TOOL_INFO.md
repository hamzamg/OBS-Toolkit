## 6. What it does

A small collection of standalone Lua scripts, each solving one task. The pinned snapshot contains seven scripts:

- `auto-execute-commands.lua` — runs a shell command when OBS starts and another when it shuts down
  (for example, starting and stopping a camera helper). This is the only script that executes processes.
- `clone-template-scene.lua` — duplicates a template scene and its sources under a new name.
- `enforce-current-scenes.lua` — keeps a defined set of scenes present and current.
- `keyboard-event-filter.lua` — maps OBS hotkeys onto synthetic keyboard events delivered to Browser Sources
  (useful for web overlays that listen for keys). It uses OBS hotkeys, not an OS-level keyboard hook.
- `production-information.lua` — writes stream/recording statistics into a text source.
- `refresh-browser-sources.lua` — reloads Browser Sources on demand.
- `source-one-of-many.lua` — shows exactly one of a group of sources.

How it works: plain Lua 5.1 scripts using the `obslua` API. They are readable end to end and have no build step.

4. Confirm: each script appears without an error in the Script Log.

1. In OBS: **Tools > Scripts**, select the script and click **-** to remove it.
2. Delete the `.lua` file if you no longer want it.
3. Rollback: re-add the previous file (or the previous version from this library) and re-apply your settings.
