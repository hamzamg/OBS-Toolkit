## 6. What it does

Libre Macros turns OBS into a scriptable console: a Lua REPL, a macro/patch system, live reload, and helper
Python scripts that talk to OBS over WebSocket. It is aimed at users who want to write code against OBS while
it runs, not at users who want a point-and-click feature.

How it works: `console.lua` compiles and runs Lua supplied at runtime (from the console or from stored patches),
and can create processes through LuaJIT FFI. A bundled Python helper connects to the OBS WebSocket server.

## 9. Uninstallation and rollback

1. In OBS: **Tools > Scripts**, select the script and click **-** to remove it.
2. Delete the `.lua` file if you no longer want it.
3. Rollback: re-add the previous file (or the previous version from this library) and re-apply your settings.
   Script settings live in the scene collection, so restoring a backed-up collection restores them.
