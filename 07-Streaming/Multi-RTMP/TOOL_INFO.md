## 6. What it does

Multi-RTMP adds extra stream outputs to OBS. Each target has its own service, server, stream key and encoder,
and can be started and stopped independently or together with the main stream. Typical uses: streaming to
YouTube and Twitch at once, or sending a backup feed to a second ingest.

How it works: a C++ OBS plugin that creates additional OBS outputs from the same scene render, using the
encoders you select per target.

## 9. Uninstallation and rollback

1. Close OBS.
2. Remove the plugin's DLL from `obs-plugins\64bit\` and its data folder from `data\obs-plugins\<plugin>\`
   (or run the installer's uninstaller if it provides one).
3. Start OBS and confirm the log no longer lists the module.
4. Rollback: restore the previous DLL/data folder from your own backup, or install the previous version from this
   library (older versions are kept under `Downloads\<version>\`).
