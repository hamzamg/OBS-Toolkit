## 6. What it does

OBS WebSocket is the API that lets other programs drive OBS: switch scenes, change source visibility, adjust
audio, start and stop recording or streaming, and subscribe to events. It has shipped bundled with OBS since
OBS 28, and the detected OBS 32.0.1 already contains version 5.6.3.

This library stores no binary for it. It snapshots the protocol documentation at tag `5.6.3` so client
configuration can be written against the exact bundled version.

## 8. Manual installation (not performed)

This library installs nothing. The steps below are for you to run later, after a backup.

### Nothing to install

OBS 32.0.1 already bundles OBS WebSocket 5.6.3 (the pinned submodule commit matches tag `5.6.3`).

1. In OBS: **Tools > WebSocket Server Settings**.
2. Keep **Enable WebSocket server** off until you actually need a client.
3. When you enable it, keep authentication on, set a unique strong password, and leave the port at the default
   4455 unless something else already uses it.
4. Confirm: the dialog shows "Server running" and a client can connect on `127.0.0.1:4455`.

Never forward port 4455, never expose it through a tunnel, and never bind it to a public interface.
