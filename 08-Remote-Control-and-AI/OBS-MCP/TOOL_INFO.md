## 6. What it does

OBS-MCP is a Model Context Protocol server that exposes OBS control as tools an AI client can call: scenes,
sources, filters, the audio mixer, streaming, recording and Studio Mode. The AI client starts it as a local
process and talks to it over stdio; the server talks to OBS over the local WebSocket.

How it works: a Python package (`obs_mcp`) built on `mcp[cli]` and `obsws-python`. Tool modules are discovered
at import time from the package, and connection settings come from `OBS_HOST`, `OBS_PORT` and `OBS_PASSWORD`.

3. Add an entry to your MCP client configuration. Shape (placeholders only, never commit real values):

```json
{
  "mcpServers": {
    "obs-mcp": {
      "command": "<path-to-venv>\\Scripts\\python.exe",
      "args": ["-m", "obs_mcp.main"],
      "env": {
        "OBS_HOST": "127.0.0.1",
        "OBS_PORT": "4455",
        "OBS_PASSWORD": "<your-websocket-password>"
      }
    }
  }
}
```

1. Confirm: the client lists the OBS tools and a read-only call (for example "get version") succeeds before you
   allow anything destructive.

## 9. Uninstallation and rollback

1. Remove the `obs-mcp` entry from your MCP client configuration.
2. Delete the virtual environment you created for it.
3. Optionally rotate the OBS WebSocket password, since the client stored it.
4. Rollback: re-add the entry and reinstall the pinned version.
