## 6. What it does

Advanced Scene Switcher automates scene and source changes from rules you build in a dock, without editing
OBS by hand. Rules can watch window titles and focus, audio levels, media state, the clock, file contents,
hotkeys, and OBS events; a macro engine adds conditions, actions, variables and loops on top.

Practical uses:

- Switch to a "Game" scene when a game window takes focus, and back to "Desktop" when it loses focus.
- Start or stop recording/streaming from a macro, or run a sequence of source visibility changes on a timer.
- React to an audio source crossing a threshold (for example, mute a music source when the mic is hot).
- Drive repeated show segments from a single "Next" hotkey.

How it works: a C++ OBS plugin that registers its own dock, rule list and macro engine, and calls the public
OBS frontend API. HTTP actions load `libcurl.dll` at runtime; process actions start programs you configure.
Imported rule/macro files therefore behave like small programs: only load files you trust.

This library installs nothing. The steps below are for you to run later, after a backup.

### Installed OBS (system-wide, `C:\Program Files\obs-studio`)

1. Back up scene collections and profiles first (`00-Documentation\OBS_BACKUP_GUIDE.md`).
2. Close OBS completely.
3. Run `advanced-scene-switcher-1.37.2-windows-x64-Installer.exe` as administrator. The installer detects the OBS folder and, per the release notes, supports OBS 32 and OBS 33.
4. Start OBS.
5. Confirm: an **Advanced Scene Switcher** entry appears under **Tools** (and its dock can be opened), and
   **Help > Log Files > View Current Log** shows the module loaded without an error.

### Portable OBS

Run the installer and point it at the portable OBS root, or use the `windows-x64-portable-obs32.zip` asset
(listed as the alternative in section 5; not downloaded). The `windows-x64.zip` asset is documented as OBS 33+
only, so do not use it on the detected OBS 32.0.1.

## 9. Uninstallation and rollback

1. Close OBS.
2. Remove the plugin's DLL from `obs-plugins\64bit\` and its data folder from `data\obs-plugins\<plugin>\`
   (or run the installer's uninstaller if it provides one).
3. Start OBS and confirm the log no longer lists the module.
4. Rollback: restore the previous DLL/data folder from your own backup, or install the previous version from this
