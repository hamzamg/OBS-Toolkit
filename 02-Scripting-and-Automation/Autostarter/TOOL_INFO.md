## 6. What it does

Autostarter launches external programs together with OBS. You define named loadouts, each a list of programs
with arguments, and launch a loadout when OBS starts or from the plugin dock. Typical uses: starting a camera
utility, a lighting app, or a chat client before a stream, and keeping those launches consistent between shows.

How it works: a C++ OBS plugin. It reads its configuration, then starts each program in the selected loadout
with `CreateProcess` (or `ShellExecuteA` for non-executable files). Command lines are stored in the plugin's
OBS configuration, not in the scene collection.
