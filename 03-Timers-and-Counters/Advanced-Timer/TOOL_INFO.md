## 6. What it does

Advanced Timer writes a live timer into a text source. Modes cover countdown, stopwatch, countdown to a clock
time, countdown to a date and time, and timers that follow streaming or recording state. Countdown modes can
switch to counting up after zero. Formatting tokens control days, hours, minutes, seconds and tenths, with
optional leading zeros and unbounded hours/minutes/seconds. Hotkeys start, stop and reset the timer, and the
timer can start when its source becomes active.

How it works: a single Lua script using the `obslua` API (`obs.timer_add`, text source updates, hotkeys). There
is no network, process or file access in the script.
