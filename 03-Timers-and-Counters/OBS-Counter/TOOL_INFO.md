## 6. What it does

OBS Counter is a Python script that turns OBS hotkeys into a counter shown in a text source. Each press of the
increment or decrement hotkey updates the text, which makes it useful for death counters, attempt counters,
scoreboards, or "sub goal" displays. Duplicating the script file under a new name gives you independent
counters.

How it works: `hotkey_counter.py` registers OBS frontend hotkeys and writes the current value into a text source
you choose. It does not use OS-level keyboard hooks, so hotkeys only fire while OBS has focus according to your
OBS hotkey settings.

## 8. Manual installation (not performed)

This library installs nothing. The steps below are for you to run later, after a backup.

### Prerequisites

- A 64-bit Python inside the OBS 32 range (3.8 <= v < 3.11). On this machine that is `C:\Python38\python.exe`.
- A text source to display the counter.

### Steps

1. Back up the scene collection.
2. Copy `hotkey_counter.py` from the pinned source snapshot to a folder you control
   (for example `%USERPROFILE%\Documents\OBS-Scripts\`). There is no release asset.
3. In OBS: **Tools > Scripts > Python Settings**, set the interpreter to the 64-bit 3.8 path above.
4. **Scripts tab > +** and select `hotkey_counter.py`.
5. Choose the text source in the script properties, then **Settings > Hotkeys** and bind the counter hotkeys.
6. Confirm: the Script Log shows no error and a hotkey press changes the text.

### Portable OBS

Identical, except Python Settings must be set inside the portable instance.
