## 6. What it does

Local Stream Marker writes stream-style markers for any OBS recording or stream, not just Twitch. A hotkey
appends a row to a CSV file with the timestamp, the current scene, the visible sources, and the recording file
name when recording. An optional end marker closes the range. The CSV opens in any spreadsheet, which makes it
easy to cut a long recording into chapters afterwards.

How it works: a single Lua script using `obslua` plus Lua's `os.date`/`os.time` and plain file I/O. The only
write is the CSV at the folder you choose (or next to the script if you leave the folder blank).

## 8. Manual installation (not performed)

This library installs nothing. The steps below are for you to run later, after a backup.

### Any OBS install (Lua)

1. Extract `local-stream-marker.1.13.zip` and keep `local-stream-marker.lua` (the zip also contains `LICENSE`, `README.md` and `CHANGELOG.md`).
2. Copy the script to a folder you control, for example `%USERPROFILE%\Documents\OBS-Scripts\`.
3. In OBS: **Tools > Scripts > +** and select `local-stream-marker.lua`.
4. In the script properties, set **Output Folder** (blank means "next to the script") and optionally the CSV
   filename and datetime format. Save your scene collection before testing a new datetime format: the README
   warns that a bad format can crash OBS.
5. Confirm: the properties panel loads, and pressing **Set Marker** creates the CSV file.

### Portable OBS

Identical.

## 9. Uninstallation and rollback

1. In OBS: **Tools > Scripts**, select the script and click **-** to remove it.
2. Delete the `.lua` file if you no longer want it.
3. Rollback: re-add the previous file (or the previous version from this library) and re-apply your settings.
   Script settings live in the scene collection, so restoring a backed-up collection restores them.
