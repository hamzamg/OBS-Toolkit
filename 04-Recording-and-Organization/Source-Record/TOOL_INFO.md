## 6. What it does

Source Record adds a filter that records one source on its own: a game capture, a camera, a specific audio
device, or a composite. Each filter creates its own OBS output, so you can record the full scene and a clean
game feed at the same time, or stream a source separately from the main recording.

Practical uses: a clean gameplay file without overlays while the main recording keeps them; an isolated camera
ISO; a separate audio-only file for editing.

How it works: a C++ OBS plugin that creates a file output, a stream output, or a replay-buffer output per
filter, using the encoder settings you pick in the filter properties.
