## 6. What it does

Advanced Filename Formatter extends OBS's recording filename templates with dynamic expressions: dates and
times, scene and source names, and other values resolved when the recording is finalized. It can also rename
finished recordings in place, which keeps a folder sortable without manual work.

How it works: a Python script loaded by OBS. Templates are compiled and evaluated with `eval(compile(...))`,
and `pyparsing` is installed at first load if it is missing.

Practical uses: `2026-11-02_GameName_1080p.mp4`-style names, per-scene folders, and consistent names across a
series without touching OBS settings each time.

### Prerequisites (blocking on this machine)

- OBS's Python must be **3.10 x64**. OBS 32 accepts 3.8 to 3.10, and the script requires 3.10 or newer, so 3.10 is

### Steps (after 3.10 exists)

1. Back up the scene collection and your recording folder naming rules.
2. Copy `adv-ff.py` to a folder you control.
3. **Tools > Scripts > Python Settings**: select the 3.10 x64 interpreter.
4. **Scripts tab > +** and select `adv-ff.py`.
5. On first load the script may run `pip install --target <OBS Python path> pyparsing`. If you do not want that
   network call, pre-install `pyparsing` into the same interpreter first.
6. Confirm: the script panel loads, a preview of the formatted name appears, and the Script Log shows no error.
