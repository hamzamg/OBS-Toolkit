## 6. What it does

Filter Hotkeys adds a filter that exposes hotkeys for the other filters on the same source. For each filter you
can bind disable (0), enable (1), toggle (2), or hold (3), so a single key can turn a blur, a color correction,
or a mask on and off during a show without opening the filters dialog. The pinned snapshot ships two variants:
`filter_hotkeys_video.lua` for video filters and `filter_hotkeys_audio.lua` for audio filters.

How it works: a Lua script that registers OBS source/filter hotkeys and flips the `enabled` state of the target
filters. No network, process or file access.

## 8. Manual installation (not performed)

This library installs nothing. The steps below are for you to run later, after a backup.

### Any OBS install (Lua)

The pinned snapshot contains **two** scripts: `filter_hotkeys_video.lua` and `filter_hotkeys_audio.lua`.
There is no release asset.

1. Back up the scene collection.
2. Copy the script(s) you need to a folder you control.
3. Add the real filters to the source **first** (the README requires this), then add the hotkey filter.
4. **Tools > Scripts > +** and add `filter_hotkeys_video.lua` and/or `filter_hotkeys_audio.lua`.
5. In the filter properties, bind hotkeys: 0 = disable, 1 = enable, 2 = toggle, 3 = hold.
6. Confirm: the filter appears on the source and the hotkeys appear under **Settings > Hotkeys**.

Identical.
